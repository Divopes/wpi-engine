Windows Post-Install 2.0
========================

Мастер установки программ после переустановки Windows (аналог WPI).
Отмечаете галочками нужные программы, нажимаете «Установить» — программы
ставятся по очереди, в тихом или обычном режиме.

Ядро написано на C и использует только Win32 API:
  * один файл wpi.exe примерно на 75 КБ, без .NET, WebView, браузера и DLL;
  * запускается мгновенно, памяти занимает несколько мегабайт;
  * работает в Windows XP, Vista, 7, 8, 10 и 11 (32-битная сборка
    работает и на x64);
  * сам запрашивает права администратора (UAC).


Структура папки для флешки / DVD
--------------------------------
  wpi.exe
  config.json        список программ
  install\           установщики
  tweaks\            .reg, .cmd и т.п.


Возможности
-----------
  * Программы сгруппированы по категориям.
  * Для каждой программы можно переключать режим «Тихая / Обычная»
    (клик по колонке «Режим»).
  * Программы, которые не подходят к системе (разрядность, версия Windows)
    или файл которых не найден, показаны серым с указанием причины.
  * Типы файлов: .exe, .msi, .msp, .msu, .bat, .cmd, .reg, .ps1, .vbs, .js.
  * Коды возврата 3010/1641 распознаются как «нужна перезагрузка».
  * Журнал в окне и в файле %TEMP%\wpi.log.
  * Автоустановка по таймеру, перезагрузка по окончании.
  * Кнопка «Остановить» — текущий установщик доустанавливается
    (прерывать его опасно), остальные пропускаются.


Командная строка
----------------
  wpi.exe                      обычный запуск, config.json рядом с exe
  wpi.exe /auto                установить выбранное по умолчанию и закрыться
  wpi.exe /config=D:\my.json   другой файл конфигурации


config.json
-----------
Обычный JSON, но для удобства ручного редактирования разрешены
комментарии // и /* */, запятая после последнего элемента и ключи без кавычек.
Файл должен быть в UTF-8.

Общие параметры:
  title    заголовок окна
  timer    через сколько секунд начать установку сама (0 — не начинать)
  reboot   галочка «Перезагрузить после» включена по умолчанию

Параметры программы (массив software):
  name                имя в списке
  cat                 категория (группа в списке)
  desc                описание во всплывающей подсказке
  exe                 путь к установщику относительно wpi.exe, можно
                      абсолютный и с переменными: %WPIROOT%, %ProgramFiles%...
                      ВАЖНО: пишите / или \\ вместо \ — иначе "\n", "\t"
                      будут прочитаны как спецсимволы.
  flag                "x64" — только 64-битная Windows,
                      "x86" — только 32-битная, пусто — любая
  support_xp          false — скрыть в Windows XP (по умолчанию true)
  support_7           false — скрыть в Vista/7; учитывается только при
                      support_xp: false (по умолчанию true)
  install_dflt        отмечена по умолчанию
  silent_supported    поддерживает тихую установку
  silent_dflt         тихий режим выбран по умолчанию (по умолчанию true)
  silent_args         аргументы для тихой установки, например /S или /qn
  normal_args         аргументы для обычной установки
  lock_silent_choice  запретить пользователю менять режим

Переменная окружения WPIROOT (папка с wpi.exe) доступна и в запускаемых
.bat/.cmd скриптах.


Сборка
------
Linux (Debian/Ubuntu):
  sudo apt install gcc-mingw-w64-i686 gcc-mingw-w64-x86-64 make
  make              -> build/wpi.exe   (32 бит, для всех систем)
  make wpi64.exe    -> build/wpi64.exe (64 бит)

Windows (MSYS2):
  pacman -S mingw-w64-i686-gcc make
  make

Исходники:
  src/main.c      окно и интерфейс
  src/config.c    чтение config.json, определение системы
  src/install.c   очередь установки (отдельный поток)
  src/json.c      маленький парсер JSON
  src/wpi.rc      ресурсы: манифест (UAC, стили, DPI), версия
